# Abuzar Ahmad - Portfolio

A professional, responsive portfolio website showcasing my full-stack development projects, skills, education, and achievements.

## 🚀 Features

- **Modern UI/UX**: Built with React and animated using Framer Motion and AOS (Animate on Scroll)
- **Responsive Design**: Fully responsive layout that looks great on all devices
- **Dynamic Content**: Data-driven components displaying projects, skills, and experience
- **Interactive Experience**: Smooth scroll navigation, hover effects, and project detail modals

## 💻 Tech Stack

- **Framework**: React (Vite)
- **Styling**: CSS3, CSS Variables for theming
- **Animations**: Framer Motion, AOS (Animate on Scroll)
- **Icons**: React Icons
- **Deployment**: Vercel

## 📂 Project Structure

```
src/
├── assets/         # Images and static files
├── components/     # Reusable UI components (Hero, Projects, Skills, etc.)
├── data/           # Data files (portfolioData.js) for easy content management
├── styles/         # Global styles and component-specific stylesheets
├── App.jsx         # Main application component
└── main.jsx        # Application entry point
```

## 🛠️ Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/abuzar9818/Portfolio.git
   ```

2. Navigate to the project directory:
   ```bash
   cd Portfolio
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

5. Open your browser and visit `http://localhost:5173`

## 📝 Customization

To customize the content of the portfolio, edit the `src/data/portfolioData.js` file. The website is data-driven, so updating this file will automatically reflect changes across the site:

- Personal Information (Name, Tagline, Contact Info)
- Skills Categories and Lists
- Featured Projects (Titles, Descriptions, Technologies, Live/GitHub Links)
- Education History
- Technical Achievements
